# Prompt Versioning

Prompt versioning is the practice of treating prompts like code, tracking changes over time with version control. This makes it possible to roll back to previous versions, compare outputs across versions, and understand what changed when behavior shifted. For FDEs handing AI systems to customers, prompt versioning is part of making those systems maintainable after the engagement ends.
